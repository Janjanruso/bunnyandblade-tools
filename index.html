Etsy API Integration

Bunnyandblade Tools

A personal shop management tool for Bunnyandblade — an Etsy shop selling digital graffiti and street art prints. This application uses the Etsy API to automate listing management, order tracking, and shop reporting.

What this app does

Listing management

Create, update, and manage Etsy listings automatically from a local pipeline.

Order tracking

Retrieve and monitor shop orders and transaction data in real time.

Shop reporting

Export shop analytics and listing performance into Google Sheets.

Privacy policy

This application is a personal tool used solely by the owner of the Bunnyandblade Etsy shop. It is not a commercial product and is not made available to third parties.

Data accessed through the Etsy API (listings, orders, shop details) is used exclusively for managing the Bunnyandblade shop. No data is sold, shared, or stored on third-party servers beyond what is necessary to operate the tool locally.

This application does not collect personal information from any Etsy users or buyers. All API access complies with Etsy's API Terms of Use.
